# Donovan

Donovan is an AI workspace: a daily brief, chats that route to skills, tools and models, projects and artifacts (Assist),
and a place to build skills, servers, workflows and models (Build).

- `apps/web`: the Angular app, built from [Trench Coat](https://github.com/adamstavely/legendary-chainsaw) components.
- `apps/api`: the NestJS API, on Postgres and Elasticsearch.

The build plan is in [docs/slice-1-plan.md](docs/slice-1-plan.md).
